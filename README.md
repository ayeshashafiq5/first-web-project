Zero Waste Food Connect 🍎
A web app that connects surplus food sources with NGOs to reduce waste.

💡 Project Overview
This system is designed to bridge the gap between food waste and hunger. It allows:
Restaurants: To post details about surplus food available for donation.
NGOs: To view nearby food listings in real-time and accept them for collection.
Real-time Updates: Uses location-based tracking to ensure quick delivery and reduce spoilage.
